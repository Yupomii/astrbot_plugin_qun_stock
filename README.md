将群友与日常水群行为全面证券化的赛博金融市场插件。支持 IPO 敲钟、ST 戴帽与破产重组、概念板块连坐暴雷、恶意收购控股、金融黑客道具商城及闭关停牌机制。

## 核心机制

1. **IPO 上市与股票代码**：群友可自主敲钟上市，每人拥有专属代码与初始发行价。
2. **ST 戴帽与破产退市**：跌破发行价 20% 或连续 3 天失联潜水自动戴帽 *ST。跌至零元强制摘牌退市，退市者需提交不少于 50 字的“破产重组路演”方可重新上市。
3. **概念板块与连坐机制**：划分深夜修仙、二次元纯度、技术整活、摸鱼躺平四大板块。龙头遭遇禁言暴雷将引发整个概念板块的恐慌性踩踏连坐。
4. **恶意收购与控股特权**：单一股民持股超 50% 达成绝对控股，可强制修改子公司企业标语，并在子公司打工领薪时依法扣除 20% 利润吸血分红！
5. **金融黑客商城**：支持使用金币购买做空报告、拔网线熔断卡、内幕消息卡。
6. **闭关停牌与复牌**：现实备考或出差可主动申请停牌锁仓，复牌时根据路演讲话判定重组涨停或利好出尽跌停。

## 常用群指令

| 指令 | 说明 | 示例 |
| --- | --- | --- |
| `/股市` 或 `/大盘` | 查看全群实时股票大盘与涨跌看板 | `/股市` |
| `/查股价 @某人` | 查看某公司的详细财务报表与大股东持仓 | `/查股价 @雨落喵~` |
| `/买入 @某人 数量` | 市价买入多头股票（支持 @ 或 QQ号） | `/买入 @雨落喵~ 100` |
| `/卖出 @某人 数量` | 卖出持有的股票套现 | `/卖出 @雨落喵~ 50` |
| `/做空 @某人 数量` | 借券沽空股票，在下跌中获利 | `/做空 @雨落喵~ 50` |
| `/持仓` | 查看个人资产总值、现金与持仓盈亏 | `/持仓` |
| `/打工` | 每日签到领工资，若被恶意控股将被扣除抽水 | `/打工` |
| `/上市申请 [板块]` | 自主敲钟挂牌上市 | `/上市申请 二次元纯度` |
| `/设置口号 @某人 口号` | 持股超50%的母公司强制修改子公司标语 | `/设置口号 @雨落喵~ 饱满打工` |
| `/申请停牌 [原因]` | 闭关锁仓停牌，冻结买卖 | `/申请停牌 闭关考研` |
| `/申请复牌 [陈词]` | 结束停牌，根据陈述诚意度判定开盘行情 | `/申请复牌 携重磅项目出山` |
| `/重组路演 [检讨文本]` | 退市破产公司提交50字路演检讨重新IPO | `/重组路演 经过深刻反思...` |
| `/道具商城` | 查看金融黑客道具货架 | `/道具商城` |
| `/购买道具 [名称]` | 购买黑客道具 | `/购买道具 做空报告` |
| `/使用道具 [名称] @某人` | 使用做空或熔断道具 | `/使用道具 拔网线卡 @某人` |
